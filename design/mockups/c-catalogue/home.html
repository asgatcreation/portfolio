Room II

How I work

I start with what must never go wrong. In a payments system it’s money counted twice; in a hospital it’s one patient’s record shown to the wrong person. Then I design so that mistake can’t happen quietly.

Money is stored as whole kobo. Every record says where it came from. Every README says what doesn’t work yet.
