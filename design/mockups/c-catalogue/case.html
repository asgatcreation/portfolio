IThe problem

Buying a car online in Nigeria usually means scrolling through unverified listings, then wiring money to a stranger. Nobody pays fifty million naira by card for a car they haven’t seen, so CarHub follows how a car sale really happens.1

“Every step has a real status, notification and email behind it.”From the project README

IITwo buyers, one car

Two people can press “Pay” for the same car in the same second. Checkout locks the car rows inside a transaction and checks they’re still available. The second buyer is told the car has just gone.2

with transaction.atomic():
    # Lock the rows so two buyers can't reserve the same car at once.
    locked = list(Car.objects.select_for_update().filter(
        pk__in=[c.pk for c in cars], status='available'))

IIIPush a nudge, not the data

Live trips, chat and notifications run over WebSockets. A broadcast only says “this trip changed”. Each screen rebuilds its own view with the same permission checks as the normal pages, after the database has committed.3
